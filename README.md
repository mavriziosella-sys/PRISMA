# Prisma

**P**ianifica · **R**isparmia · **I**nvesti · **S**pendi · **M**onitora · **A**nalizza
*Plan · Reserve · Invest · Spend · Monitor · Analyze*

App personale per entrate, uscite, tetti di spesa, obiettivi di risparmio e patrimonio.
Si installa su iPhone da Safari con «Aggiungi alla schermata Home» e funziona anche senza rete.

I dati restano solo sul telefono (IndexedDB): questo repository contiene soltanto il codice.
